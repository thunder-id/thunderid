# `getSessionCookieOptions()`

`getSessionCookieOptions` merges the provided partial [`CookieOptions`](../cookie-options) with the default values from [`CookieConfig`](../cookie-config). Any property you omit falls back to its default.

## Signature

```ts
getSessionCookieOptions(options: Partial<CookieOptions>): CookieOptions
```

## Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :---: | :--- |
| `options` | `Partial<CookieOptions>` | ✅ | Cookie options to apply. Unspecified properties use the defaults from `CookieConfig`. |

## Returns

`CookieOptions`: A complete cookie options object with all required fields populated.

## Default Values

| Property | Default |
| :--- | :--- |
| `httpOnly` | `true` |
| `maxAge` | `3600` seconds (1 hour) |
| `sameSite` | `'strict'` |
| `secure` | `true` |

## Usage

### Use Defaults with a Custom Lifetime

```ts showLineNumbers
import { getSessionCookieOptions } from '@thunderid/node'

// Override only maxAge; all other properties use defaults
const options = getSessionCookieOptions({ maxAge: 86400 }) // 24 hours
```

### Override Multiple Options

```ts showLineNumbers
import { getSessionCookieOptions } from '@thunderid/node'

const options = getSessionCookieOptions({
  maxAge: 7200,
  sameSite: 'strict',
  secure: true,
})
```

### Apply to a Response Cookie

```ts title="src/routes/callback.ts" showLineNumbers
import { CookieConfig, getSessionCookieOptions, renderSignInContinuePage } from '@thunderid/node'

// The sign-in in progress travels in a Lax cookie set when sign-in started, because the Strict session cookie
// does not come back on the redirect from the identity provider.
const SIGN_IN_COOKIE = CookieConfig.getTempSessionCookieName() // thunderid-session-state
const SESSION_COOKIE = CookieConfig.getSessionCookieName() // thunderid-session

app.get('/callback', async (req, res) => {
  const sessionId = req.cookies[SIGN_IN_COOKIE]

  await auth.signIn(() => {}, sessionId, req.query.code as string, req.query.state as string)

  res.cookie(SESSION_COOKIE, sessionId, { ...getSessionCookieOptions({}), maxAge: 3600 * 1000, path: '/' })
  res.clearCookie(SIGN_IN_COOKIE, { path: '/' })

  // A redirect here would still belong to the identity provider's cross-site chain, so the browser would leave out
  // the Strict cookie just set. This page moves on from the app's own site instead.
  res.type('html').send(renderSignInContinuePage('/dashboard'))
})
```
